# Data Gathering with Python

The first step of every data-science project is **getting the data**. These notebooks show how to load
data from the most common sources with **Pandas**.

| Folder | What you learn | Sample data |
|---|---|---|
| `data gathering/working with csv file/` | `read_csv` options: separators, headers, encodings, chunks | IPL matches, Zomato, movie titles |
| `data gathering/working with json and sql/` | `read_json`, and reading tables from **MySQL** with `read_sql_query` | `train.json`, `world.sql` |

To run the SQL notebook, import `world.sql` into a local MySQL server first.
